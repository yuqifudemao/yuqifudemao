# 书页 PDF 1.0

安卓本地电子书转换工具。Android 8.0 及以上，无联网权限、无广告、无登录。

## 使用

1. 安装 `BookPDF-1.0.apk`。它是自签名测试包，并非应用商店版本。
2. 点击“选择本地书籍”，从系统文件选择器中选文件。
3. 调整字号、编码后，点击“应用设置 / 刷新预览”。纸张与页边距用于导出。
4. 点击“导出 PDF”，在安卓打印界面选择“另存为 PDF”，点击保存图标并选择目录。具体按钮文字由手机系统决定。

## 格式支持

| 输入 | 处理方式 |
| --- | --- |
| EPUB | 按 spine 章节顺序重排正文；保留常见标题、列表、表格、PNG/JPEG/GIF/WebP 图片；章节另起一页 |
| TXT | UTF-8、GB18030 自动识别；支持 UTF-16 BOM；可手选编码 |
| HTML/HTM/XHTML | 提取可见文字后重新排版，不保留原网页图片和版式 |
| DOCX | 提取正文、表格及常见内嵌图片；复杂样式、列表编号、页眉页脚、公式、浮动对象不保留 |

不支持 MOBI、AZW/AZW3、DJVU、CHM、旧版 DOC、加密书籍和 DRM。
不会转换扫描图片中的文字，不提供 OCR。
单文件上限 40MB，压缩内容累计上限 80MB，单张图片上限 8MB。长篇或图多的书仍可能受手机可用内存及系统打印服务限制。

## 构建

用 Android Studio 打开本目录，使用 JDK 17、Android SDK 35、Gradle 8.9（需自行安装 Gradle 或让 Android Studio 配置）和 AGP 8.7.3，同步后运行 `gradle assembleDebug`。项目不包含 Gradle Wrapper 二进制文件，也不含签名私钥。自行编译的签名与当前安装包不同，通常须先卸载再安装。

## 隐私及实现

只读取手动选择的文件；应用未声明 INTERNET 或全盘存储权限。输入解析在工作线程执行，WebView 禁用 JavaScript、网络和文件访问。EPUB 不落盘解压，限制解压总量，拒绝自定义 DTD 实体与外部实体。输出由 Android PrintManager 的 WebView 打印管线生成，文件位置由系统对话框选择。没有上传服务。

## 验证范围

完成 Java 编译、APK 资源打包和签名验证，并使用构造文件测试 UTF-8/GB18030/UTF-16 文本、EPUB 顺序/图像/路径、DOCX 内容和不安全实体拦截。当前环境无安卓真机或模拟器，未验证手机安装、预览、中文打印及最终导出流程。安装后应先用一份短文件试转。

这是可安装的首版测试应用，复杂电子书的保真排版仍需真实样本继续验证。
