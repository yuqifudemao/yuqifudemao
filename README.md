# 书页 PDF · BookPDF

**在安卓手机上，把电子书转换成 PDF。**

EPUB / TXT / HTML / DOCX → 预览与重新排版 → 保存 PDF

本地处理 · 无联网权限 · 无账号 · 无广告

**[下载安装包](BookPDF/downloads/BookPDF-1.0.apk?raw=true)** · [查看源码](BookPDF/) · [详细说明](BookPDF/README.md) · [反馈问题](https://github.com/yuqifudemao/yuqifudemao/issues)

> 当前版本为 **1.0 测试版**，适用于 Android 8.0 及以上。已完成编译、签名验证和 14 项解析检查；尚未完成安卓真机上的安装、预览及 PDF 导出验证。建议先用一份短文件试转。

## 能做什么

| 功能 | 说明 |
| --- | --- |
| 本地选书 | 通过系统文件选择器打开手机里的电子书 |
| 正文预览 | 转换前查看解析后的内容 |
| 字号设置 | 12 / 14 / 16 / 18 pt |
| 导出设置 | A4 / A5 纸张，三档页边距 |
| 中文编码 | 自动识别 UTF-8 / GB18030，支持带 BOM 的 UTF-16，也可手动指定 |
| 保存 PDF | 调用安卓系统打印界面，选择“另存为 PDF”并指定目录 |
| 离线使用 | 不上传书籍，不依赖服务器 |

## 下载与使用

1. 点击上方 **下载安装包**。如果 GitHub 打开文件详情，点击下载按钮获取 APK。
2. 安装并打开 **书页 PDF**。若手机提示安装权限，只为用于打开 APK 的应用允许本次安装。
3. 点击 **选择本地书籍**，打开 EPUB、TXT、HTML 或 DOCX 文件。
4. 需要调整字号或文本编码时，修改后点击 **应用设置 / 刷新预览**。
5. 点击 **导出 PDF**，在系统打印界面选择 **另存为 PDF**，点击保存图标并选择目录。

这是自行签名的测试安装包，不是应用商店发行版本。手机系统不同，安装和打印按钮的名称可能略有差异。

## 支持哪些格式

| 输入格式 | 保留内容与处理方式 | 首版限制 |
| --- | --- | --- |
| EPUB | 按书籍章节顺序重新排版，保留常见标题、段落、列表、表格和内嵌图片 | 不保留原书字体与 CSS，不支持 DRM；章节另起一页 |
| TXT | 保留文字和换行，支持中文编码选择 | 不自动识别章节目录 |
| HTML / HTM / XHTML | 提取文字后重新排版 | 不保留网页图片和原始版式 |
| DOCX | 提取正文、表格和常见内嵌图片 | 不保留复杂样式、列表编号、页眉页脚、公式和浮动对象 |

**暂不支持：** MOBI、AZW / AZW3、DJVU、CHM、旧版 DOC、加密书籍，以及扫描件 OCR。EPUB 和 DOCX 的图片支持 PNG、JPEG、GIF、WebP；大图片可能被跳过。

单个原文件不超过 **40MB**；压缩内容累计不超过 **80MB**；单张图片不超过 **8MB**。长篇、图多的文件还会受到手机内存和系统打印服务限制。

## 常见问题

**为什么点击导出后进入了打印界面？**

这是当前版本的保存方式。在打印目标里选择“另存为 PDF”，不需要连接打印机。

**中文乱码怎么办？**

对 TXT 或 HTML 依次尝试 UTF-8、GB18030，点击“应用设置 / 刷新预览”。带 BOM 的 UTF-16 文本可自动识别。

**为什么和原书排版不同？**

当前版本会提取内容并统一排版。适合阅读和打印正文，复杂文档不能保证原样还原。

**EPUB 提示无法解析或含加密资源？**

先确认文件完整、可被其他阅读器打开。含加密资源的 EPUB 暂不支持；损坏或结构特殊的文件也可能解析失败。

**转换失败后如何反馈？**

在 Issues 中说明手机型号、安卓版本、文件格式与大小、出现问题的步骤，以及错误提示。提供样本前请先去除个人隐私，并确认文件可以分享。

## 开发与构建

源码位于 [`BookPDF/`](BookPDF/)。使用 Android Studio 打开该文件夹。

| 环境 | 版本 |
| --- | --- |
| JDK | 17 |
| Android SDK | 35 |
| Gradle | 8.9 |
| Android Gradle Plugin | 8.7.3 |
| 最低安卓版本 | Android 8.0 / API 26 |

项目没有附带 Gradle Wrapper。配置好 Gradle 和 SDK 后，在 `BookPDF` 目录运行：

```sh
gradle assembleDebug
```

运行与安卓界面无关的解析检查（需要 JDK）：

```sh
javac -encoding UTF-8 -d build/parser-tests app/src/main/java/cn/bookpdf/app/BookParser.java tests/ParserTest.java
java -cp build/parser-tests cn.bookpdf.app.ParserTest
```

解析检查覆盖文本编码、EPUB 章节顺序和图片路径、DOCX 正文及表格、危险实体拦截、格式和体积限制。通过解析检查不代表最终打印流程已在手机上验证。

## 隐私

应用只读取你主动选择的文件。未声明联网权限或全盘存储权限；预览禁用 JavaScript、网络加载及文件访问。书籍在手机本地解析，输出保存位置由系统界面选择。
